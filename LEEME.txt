ARCHIVOS
  index.html        la carta (aquí se editan precios, textos y datos del local)
  logo.png          logo de MAFIA
  *.jpg             fotos de los platos (margarita.jpg, tgm.jpg, ...)

SUBIR A GITHUB
  1. Descomprime el zip.
  2. En el repositorio: Add file > Upload files.
  3. Abre la carpeta descomprimida, selecciona TODOS los archivos (Ctrl+A) y arrástralos.
     Son 17 archivos, ninguno se llama igual.
  4. Commit changes.
  5. Netlify: Add new site > Import an existing project > GitHub > tu repositorio > Deploy.
  La carta queda en tu dirección de Netlify y la maqueta en /panel-demo
